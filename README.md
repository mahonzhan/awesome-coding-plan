## 📖 术语说明

- **周期**：`5h` = 5小时 \| `w` = 周 \| `mo` = 月
- **额度倍率**：`当前周期额度 ÷ 包月价格`（认可该模型单位定价的前提下，倍率越高，代表性价比越高）
